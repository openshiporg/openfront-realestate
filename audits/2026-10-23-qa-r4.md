### QA-003 · storefront · The home page title repeats the brokerage name (regression from round-3 QA-006)
- URL: https://openfront-real-estate-production.up.railway.app/
- Steps: Open the home page and read the browser tab, or `curl -s / | grep '<title>'`.
- Expected: "Real Estate QA Demo — Batch 2" (`og:title` and `twitter:title` already say this).
- Actual: `<title>Real Estate QA Demo — Batch 2 · Real Estate QA Demo — Batch 2</title>`. This happens on every home URL (`/?type=rent`, `/?q=…`) and is what search engines show.
- Cause: The round-3 root layout added `template: "%s · <name>"`. The storefront layout's `title.default` (the brokerage name) is a child segment, so the root template wraps it again.
- Likely file: `app/(storefront)/layout.tsx:24`. Use `title: { absolute: settings.businessName, template: … }`, or drop the template from one of the two layouts. Also check `app/layout.tsx:21` for the "Coming soon" and "Unavailable" states.
